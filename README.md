5 teknis dalam pembuatan Android App menggunakan Android Studio :
1. Mengubah tampilan UI,yaitu mengedit warna,ukuran,font,tombol,dan layout.
2. Mengubah kode program,yaitu mengedit kotlin/java untuk mengubah fungsi aplikasi
3. Menambah fitur,misalnya menambahkan login ,tombol,halaman baru,atau database
4. Mengubah gambar dan ikon,yaitu mengganti logo,bacjround,atau gambar aplikasi
5. Debugging dan testing,yaitu menjalankan aplikasi ,menemukan error,lalu memperbaiki kodenya.
